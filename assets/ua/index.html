Про мене

Спеціалізуюся на створенні адаптивних веб-сайтів, які коректно працюють на всіх пристроях та в різних браузерах.

Працюю з HTML, SCSS, Bootstrap та JavaScript. Верстаю на Flexbox та CSS Grid, роблю адаптивні інтерфейси та стежу за кросбраузерністю. Підключаю API сервісів через Fetch, додаю анімації та інтерактивність. Використовую Gulp для автоматизації рутини.

Мій підхід – писати валідний, зрозумілий код та оптимізувати продуктивність. Ретельно тестую результат на різних пристроях. Прагну не просто вирішити завдання, а зрозуміти оптимальний спосіб її вирішення та довести проект до якісного результату.
