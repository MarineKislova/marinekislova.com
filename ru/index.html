Обо мне

Специализируюсь на создании адаптивных веб-сайтов, которые корректно работают на всех устройствах и в разных браузерах.

Работаю с HTML, SCSS, Bootstrap и JavaScript. Верстаю на Flexbox и CSS Grid, делаю адаптивные интерфейсы и слежу за кроссбраузерностью. Подключаю API сервисов через Fetch, добавляю анимации и интерактивность. Использую Gulp для автоматизации рутины.

Мой подход — писать валидный, понятный код и оптимизировать производительность. Тщательно тестирую результат на разных устройствах. Стремлюсь не просто решить задачу, а понять оптимальный способ её решения и довести проект до качественного результата.
